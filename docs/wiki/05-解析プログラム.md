# 📊 5. 解析プログラム

## 5.1 analyze_datas.py（統合データ解析）

### 概要

実験で取得した複数のCSVファイルを統合し、リサンプリング・角度計算・可視化を行うメイン解析プログラム。

- **ファイルパス**: [analyze_datas.py](../analyze_datas.py)

### 入力ファイル

| ファイル | 必須 | 説明 |
|---------|------|------|
| `*_experiment_log.csv` | ✓ | 実験条件情報 |
| `*_random_dot_trial_1.csv` | ✓ | ドット位置データ |
| `*_accel_log_serial_trial_1.csv` | ✓ | 加速度データ |
| `dac_output_red/green.csv` | gvs/all | GVSパターン |
| `audio_*_integrated_analysis.csv` | audio/all | 音響パターン |

### 出力ファイル

| ファイル | 説明 |
|---------|------|
| `*_integrated_analysis.csv` | 統合データ（60Hzリサンプリング済） |
| `*.png` | 解析グラフ（加速度、ドット位置、角度変化） |

### 主要処理

1. **データ読み込み**: セッション単位でファイル探索・読み込み
2. **リサンプリング**: 全データを60Hzに統一（アンチエイリアシングフィルタ適用）
3. **角度計算**: 重力正規化オイラー角の算出
4. **統合**: 加速度、ドット位置、GVS、音響データを時間軸で結合
5. **可視化**: サブプロット形式でグラフ出力

### データ整形詳細

```python
# リサンプリング処理
TARGET_FS = 60.0  # Hz
ANTI_ALIAS_CUTOFF = 24  # Hz (ナイキスト30Hz × 0.8)

# 重力正規化オイラー角計算
roll = arctan2(accel_y_norm, accel_z_norm)
pitch = arctan2(-accel_x_norm, sqrt(accel_y_norm² + accel_z_norm²))
angle_change = roll  # メインの角度変化指標
```

### 使用例

```bash
# フォルダ指定
python analyze_datas.py hatano/

# 全被験者解析
python analyze_datas.py .
```

## 5.2 postural_sway_analyzer.py（身体動揺解析）

### 概要

integrated_analysisファイルに3Hzローパスフィルタを適用し、身体動揺成分を抽出・解析。

- **ファイルパス**: [postural_sway_analyzer.py](../postural_sway_analyzer.py)

### 入力ファイル

| ファイル | 説明 |
|---------|------|
| `*_integrated_analysis.csv` | 統合データ |

### 出力ファイル

| ファイル | 説明 |
|---------|------|
| `*_integrated_analysis_sway_3.0Hz.csv` | 3Hzフィルタ適用データ |
| `correlation_summary_3.0Hz.csv` | 相関係数統計サマリー |
| `*.png` | 身体動揺グラフ |

### 主要処理

1. **フィルタ処理**: 4次バターワース3Hzローパスフィルタ
2. **データ切り出し**: 指定時間範囲でトリミング（デフォルト: 20-300秒）
3. **窓相関計算**: 10秒窓での移動相関係数
4. **統計計算**: 平均、標準偏差、四分位数

### 設定パラメータ

```python
DATA_START_TIME = 20.0   # 開始時刻（秒）
DATA_END_TIME = 300.0    # 終了時刻（秒）
ENABLE_AUDIO_FILTER = False
```

### 使用例

```bash
python postural_sway_analyzer.py hatano/
python postural_sway_analyzer.py .
```

## 5.3 phase_correlation_analyzer.py（位相相関解析）

### 概要

ロックインアンプ原理を用いてangle_changeと各刺激の位相差・位相相関を計算。

- **ファイルパス**: [phase_correlation_analyzer.py](../phase_correlation_analyzer.py)

### 入力ファイル

| ファイル | 説明 |
|---------|------|
| `*_integrated_analysis.csv` | 統合データ |

### 出力ファイル

| ファイル | 出力先 | 説明 |
|---------|-------|------|
| `*_phase_analysis_3.0Hz.csv` | `phase/` | 位相データ |
| `*_window_correlations_3.0Hz.csv` | `phase/correlation_visualizations/` | 窓相関データ |
| `*_filtered_signals.png` | `phase/correlation_visualizations/` | フィルタ信号グラフ |
| `*_window_correlations.png` | `phase/correlation_visualizations/` | 窓相関グラフ |

### 位相計算原理

```python
# ロックインアンプ原理
reference_sin = sin(2π × target_frequency × t)
reference_cos = cos(2π × target_frequency × t)

I = lowpass(signal × reference_cos)  # 同相成分
Q = lowpass(signal × reference_sin)  # 直交成分

phase = arctan2(Q, I)
phase = unwrap(phase)  # 位相連続化
```

### 使用例

```bash
python phase_correlation_analyzer.py hatano/
```
