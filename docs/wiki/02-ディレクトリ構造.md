## 2.3 条件フォルダの説明

| フォルダ名 | 説明 | 含まれる刺激 |
|-----------|------|-------------|
| `vis` | 視覚のみ | ランダムドット |
| `audio` | 聴覚 | ランダムドット + 音響 |
| `gvs` | GVS | ランダムドット + GVS |
| `all` | 全刺激 | ランダムドット + 音響 + GVS |
| `inv_gvs` | GVS反転 | ランダムドット + GVS（逆位相） |

## 2.4 ファイル命名規則

### タイムスタンプ形式
```
YYYYMMDD_HHMMSS_<ファイル種別>.csv
```

例: `20250929_001634_experiment_log.csv`
- `20250929`: 2025年9月29日
- `001634`: 00時16分34秒
- `experiment_log`: ファイル種別

### ファイル種別一覧

| ファイル名パターン | 説明 |
|-------------------|------|
| `*_experiment_log.csv` | 実験設定ログ |
| `*_random_dot_trial_1.csv` | ランダムドット位置データ |
| `*_accel_log_serial_trial_1.csv` | 加速度センサデータ |
| `*_audio_trial_1.csv` | 音響データ |
| `*_gvs_trial_1.csv` | GVSデータ |
| `*_integrated_analysis.csv` | 統合解析結果 |
| `*_sway_3.0Hz.csv` | 身体動揺フィルタ適用データ |
| `*_phase_analysis_3.0Hz.csv` | 位相解析結果 |
| `*_window_correlations_3.0Hz.csv` | 窓相関解析結果 |

## 2.5 解析出力フォルダ

解析プログラムは入力フォルダと同じ場所に出力を生成します：

```

├── [入力ファイル群]
├── *_integrated_analysis.csv              # analyze_datas.py出力
```
