## 7.2 メイン解析プログラム

### analyze_datas.py

```bash
python analyze_datas.py <input_path>
```

| 引数 | 必須 | 説明 | 例 |
|------|------|------|-----|
| `input_path` | ✓ | 被験者フォルダまたはファイルパス | `hatano/`, `.` |

**使用例**:
```bash
# 特定被験者の解析
python analyze_datas.py hatano/

# カレントディレクトリ全体を解析
python analyze_datas.py .

# 特定条件フォルダの解析
python analyze_datas.py hatano/vis/
```

### analyze_acceleration.py

```bash
python analyze_acceleration.py <input_path>
```

| 引数 | 必須 | 説明 | 例 |
|------|------|------|-----|
| `input_path` | ✓ | フォルダまたはCSVファイル | `hatano/vis/`, `*.csv` |

**ファイル内設定**:
```python
SPLIT_PLOTS_BY_TIME = True
SPLIT_DURATION = 200      # 分割時間（秒）
START_TIME = 0            # 解析開始時間(s)
FILTER_CUTOFF_HZ = 2      # ローパスフィルタカットオフ (Hz)

CORR_WINDOW_SIZE_SEC = 10   # 相関解析窓サイズ（秒）
CORR_STEP_SIZE_SEC = 1      # 相関解析ステップ（秒）

COHERENCE_WINDOW_SIZE_SEC = 10  # コヒーレンス窓サイズ
TARGET_FREQ_HZ = 0.1        # 目標周波数（Hz）
```

**使用例**:
```bash
python analyze_acceleration.py hatano/vis/
python analyze_acceleration.py hatano/vis/*_accel_log_serial_trial_1.csv
```

## 7.7 一括実行スクリプト

### run_analysis.sh

```bash
#!/bin/bash
# 全被験者の解析を一括実行

subjects=("hatano" "fujimoto" "sugihara")

for subject in "${subjects[@]}"; do
    echo "=== Processing $subject ==="
    python analyze_datas.py "$subject/"
    python postural_sway_analyzer.py "$subject/"
    python phase_correlation_analyzer.py "$subject/"
done

# 条件比較
for subject in "${subjects[@]}"; do
    python phase_condition_comparison_analyzer.py "$subject"
done

# 占有時間解析
python phase_occupancy_analyzer.py "${subjects[@]}"
```
