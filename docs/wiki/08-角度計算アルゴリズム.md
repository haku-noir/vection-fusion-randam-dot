# 角度計算アルゴリズム

本ドキュメントでは、`analyze_datas.py`における身体動揺角度の計算処理について詳細に説明します。

## 1. 概要

M5Stack Core2に搭載されたIMU（慣性計測装置）から取得した加速度データを用いて、被験者の身体傾斜角度を計算します。

### 実験装置構成

```
          スクリーン
             ↑ (前方)
             |
    被験者 ← M5Stack (頭部装着)
             |
           ↓ (重力方向)
```

### 重要な前提

**計算される角度は「センサ自体の傾斜角度」であり、「足元を中心とした回転角度」ではありません。**

```
✅ 正しい解釈：          ❌ 誤った解釈：
                    
     鉛直線                    ● センサ
       |                      ╱
       |  θ ← センサの傾き   ╱ θ ← 足元中心の回転？
       | ╱                   ╱
       |╱                   ╱
  ┌────────┐               ●───────  足元
  │M5Stack │             
  └────────┘             
```

## 2. 加速度センサの原理

### 加速度センサが測定しているもの

加速度センサは**その場所での重力ベクトルの方向**を検出します。

```
静止状態のセンサ：

    センサ座標系        実際に測定される加速度
         Z↑                    ↑ 
         |                     | 重力の反作用
         |                     | （約9.8 m/s²上向き）
    Y←---+--→X                 |
         |                     
```

**重要**: 静止時、加速度センサは「重力と反対方向」の加速度を検出します。

### センサが傾いたとき

```
センサが右に θ 度傾いた場合：

        Z'↑    
          \    重力ベクトル（常に鉛直下向き）
           \        ↓
            \       ↓
    Y'←------\------↓
              \     ↓
               \    ↓
                   ↓g

センサから見た重力の分解：
- Z'軸成分: g × cos(θ)
- Y'軸成分: g × sin(θ)  ← これが横方向に現れる
```

## 3. M5Stackの生データ

M5Stackは3軸加速度を取得します：

| 変数 | 説明 | 単位 |
|------|------|------|
| `accel_x` | X軸加速度 | m/s² |
| `accel_y` | Y軸加速度 | m/s² |
| `accel_z` | Z軸加速度 | m/s² |

### M5Stack側の処理（main.cpp）

```cpp
// 単位変換定数
const float G_TO_MS2 = 9.80665;

// 加速度取得
float accX_g, accY_g, accZ_g;
M5.IMU.getAccelData(&accX_g, &accY_g, &accZ_g);

// m/s²に変換
float raw_x = accX_g * G_TO_MS2;
float raw_y = accY_g * G_TO_MS2;
float raw_z = accZ_g * G_TO_MS2;
```

## 4. 重力正規化座標系の構築

`analyze_datas.py`の`merge_experiment_data`関数で、重力方向を基準とした新しい座標系を構築します。

### Step 1: 重力方向の推定

実験中の加速度データの時間平均から重力方向を推定します。

$$\vec{g}_{avg} = \frac{1}{N}\sum_{i=1}^{N} \vec{a}_i$$

$$\hat{g} = \frac{\vec{g}_{avg}}{|\vec{g}_{avg}|}$$

```python
# 平均ベクトル（重力方向）を計算
gravity_vector = np.mean(accel_data, axis=0)
gravity_magnitude = np.linalg.norm(gravity_vector)

# 正規化された重力方向
gravity_unit = gravity_vector / gravity_magnitude
```

### Step 2: 新しい座標系の構築

| 軸 | 定義 | 物理的意味 |
|----|------|-----------|
| **new_z** | $\hat{g}$ | 重力方向（下向き） |
| **new_x** | 元のZ軸から重力成分を除去した方向の負 | 前後方向 |
| **new_y** | $\hat{g} \times \vec{x}_{new}$（右手系） | 左右方向 |

#### 数式表現

$$\vec{z}_{new} = \hat{g}$$

$$\vec{x}_{temp} = \vec{z}_{orig} - (\vec{z}_{orig} \cdot \hat{g})\hat{g}$$

$$\vec{x}_{new} = -\frac{\vec{x}_{temp}}{|\vec{x}_{temp}|}$$

$$\vec{y}_{new} = \vec{z}_{new} \times \vec{x}_{new}$$

```python
# 新しいZ軸: 重力方向
new_z = gravity_unit

# 元のZ軸方向から重力成分を除去
original_z = np.array([0, 0, 1])
temp_x = original_z - np.dot(original_z, new_z) * new_z
new_x = -temp_x / np.linalg.norm(temp_x)

# 新しいY軸: 右手系でZ×X
new_y = np.cross(new_z, new_x)
```

### Step 3: 座標変換

各時刻の加速度ベクトルを新しい座標系に変換します。

$$a_{x,norm} = \vec{a} \cdot \vec{x}_{new}$$

$$a_{y,norm} = \vec{a} \cdot \vec{y}_{new}$$

$$a_{z,norm} = \vec{a} \cdot \vec{z}_{new}$$

```python
for i, accel in enumerate(accel_data):
    normalized_accel[i, 0] = np.dot(accel, new_x)  # X成分
    normalized_accel[i, 1] = np.dot(accel, new_y)  # Y成分
    normalized_accel[i, 2] = np.dot(accel, new_z)  # Z成分
```

## 5. Roll（左右傾斜角）の詳細計算

### 幾何学的導出

Rollは左右方向の傾きを表し、前後軸（X軸）周りの回転角度です。

```
後ろから見た図（センサが右に θ 度傾いた状態）：

            鉛直
              |
              |
         θ ╱  |
          ╱   |
    Z'   ╱    | g×cos(θ)  ← Z軸方向の加速度成分
        ╱     |
       ╱______|
      ↙ Y'
    g×sin(θ)  ← Y軸方向の加速度成分

三角関数より：
tan(θ) = (Y方向の加速度) / (Z方向の加速度)
       = (g×sin(θ)) / (g×cos(θ))
       = ay / az
```

### 計算式

$$\text{roll} = \arctan2(a_{y,norm}, a_{z,norm}) \times \frac{180}{\pi}$$

```python
merged_df['roll'] = np.arctan2(
    merged_df['accel_y_norm'],  # Y軸加速度（左右方向）
    merged_df['accel_z_norm']   # Z軸加速度（鉛直方向）
) * 180 / np.pi
```

### なぜ arctan2 を使うか？

| 関数 | 出力範囲 | 問題点 |
|------|----------|--------|
| `arctan(y/z)` | -90° ~ +90° | z=0でゼロ除算、象限の区別不可 |
| `arctan2(y, z)` | -180° ~ +180° | 全象限を正しく処理、ゼロ除算なし |

```python
# arctan の問題例
import numpy as np

# z = 0 の場合
np.arctan(1 / 0)  # → エラー！

# arctan2 なら安全
np.arctan2(1, 0)  # → π/2 (90°)
```

## 6. Pitch（前後傾斜角）の詳細計算

### 幾何学的導出

Pitchは前後方向の傾きを表し、左右軸（Y軸）周りの回転角度です。

```
横から見た図（センサが後ろに φ 度傾いた状態）：

              鉛直
                |
           φ ╱  |
            ╱   |
    Z'     ╱    | 
          ╱     |
    X' ←─╱──────|
   g×sin(φ)     |
                |
          √(ay² + az²) = g×cos(φ)  ← YZ平面への投影長
```

### 計算式

$$\text{pitch} = \arctan2\left(-a_{x,norm}, \sqrt{a_{y,norm}^2 + a_{z,norm}^2}\right) \times \frac{180}{\pi}$$

```python
merged_df['pitch'] = np.arctan2(
    -merged_df['accel_x_norm'],                                           # X軸加速度（前後方向）の負
    np.sqrt(merged_df['accel_y_norm']**2 + merged_df['accel_z_norm']**2)  # YZ平面への投影
) * 180 / np.pi
```

### なぜ √(ay² + az²) を使うか？

Pitchを計算するとき、Rollの影響を除去するためです。

```
3D空間での重力ベクトル分解：

         az (鉛直成分)
          ↑
          |      ／ ay (左右成分)
          |    ／
          |  ／ √(ay² + az²) = YZ平面への投影長
          |／_____________→ ax (前後成分)

pitch = arctan2(-ax, √(ay² + az²))

これにより、rollがどんな値でもpitchを正しく計算できる
```

## 7. 3次元加速度から求められる角度

### 求められる角度と求められない角度

| 角度 | 回転軸 | 計算可能？ | 理由 |
|------|--------|----------|------|
| **Roll** | 前後軸（X軸） | ✅ Yes | 重力ベクトルのY,Z成分から計算 |
| **Pitch** | 左右軸（Y軸） | ✅ Yes | 重力ベクトルのX成分とYZ投影から計算 |
| **Yaw** | 鉛直軸（Z軸） | ❌ No | 水平面内の回転は重力に影響しない |

### なぜYaw（水平回転）は求められないか

```
上から見た図：

    Yaw回転（水平面での回転）
         ↺
    ┌────────┐
    │        │
    │センサ  │  → 重力ベクトルは常に下向き
    │        │     （yaw回転しても変化しない）
    └────────┘

加速度センサは重力方向を検出するため、
水平面内の回転（yaw）は原理的に検出できない
```

## 8. 角度の正規化

角度を-180°から+180°の範囲に収めます。

$$\text{normalize}(\theta) = ((\theta + 180) \mod 360) - 180$$

```python
def normalize_angle(angle):
    """角度を-180から+180度の範囲に正規化"""
    return ((angle + 180) % 360) - 180

merged_df['roll'] = normalize_angle(merged_df['roll'])
merged_df['pitch'] = normalize_angle(merged_df['pitch'])
```

## 9. 角度変化の計算

実験開始時（t=0）の姿勢を基準とした角度変化を計算します。

$$\text{roll\_change} = \text{normalize}(\text{roll} - \text{roll}_{t=0})$$

$$\text{pitch\_change} = \text{normalize}(\text{pitch} - \text{pitch}_{t=0})$$

```python
initial_roll = merged_df['roll'].iloc[0]
initial_pitch = merged_df['pitch'].iloc[0]

roll_diff = merged_df['roll'] - initial_roll
pitch_diff = merged_df['pitch'] - initial_pitch

merged_df['roll_change'] = normalize_angle(roll_diff)
merged_df['pitch_change'] = normalize_angle(pitch_diff)
```

### angle_change

主要な解析対象として、roll（左右動揺）を`angle_change`に設定します。

```python
merged_df['angle_change'] = merged_df['roll']
```

## 10. 角度の基準点について

### 重要：「回転中心」という概念はない

加速度センサで計算される角度は**センサ自体の傾斜角度**です。「足元を中心とした回転角度」ではありません。

```
この実験で測定しているもの：

     鉛直線（重力方向）
         |
         |  θ ← この角度を測定
         | ╱
         |╱
    ┌────────┐
    │M5Stack │  ← センサの傾き
    │  IMU   │
    └────────┘

「どこを中心に回転しているか」は
加速度センサだけでは分からない
```

### 倒立振子モデル（追加の仮定）

身体動揺研究で「足首を回転中心」と解釈するには、以下の**追加の仮定**が必要です：

```
倒立振子モデル：

1. 身体は剛体（曲がらない棒）
2. 足首だけが回転する
3. センサの傾き ≈ 身体全体の傾き

         ● 頭部（センサ）
        ╱|
       ╱ |
      ╱  | 
     ╱   | h = L × cos(θ)
    ╱    |
   ╱ θ   |
  ╱______|
 ●───────→ d = L × sin(θ)
足首（回転中心）

この仮定のもとで：
   頭部変位 d = L × sin(θ)
   L: 足首からセンサまでの距離
```

**これは物理法則ではなく、生体力学的なモデル（仮定）です。**

### 変位への変換（オプション）

倒立振子モデルを仮定する場合、角度から変位を計算できます：

$$d_{左右} = L \times \sin(\text{roll})$$

$$d_{前後} = L \times \sin(\text{pitch})$$

```python
# 例：身長170cm、足首高さ8cmの場合
EFFECTIVE_LENGTH = 1.70 - 0.08  # = 1.62 m

# 左右変位
displacement_x = EFFECTIVE_LENGTH * np.sin(np.radians(merged_df['roll']))

# 前後変位
displacement_y = EFFECTIVE_LENGTH * np.sin(np.radians(merged_df['pitch']))
```

| 変数名 | 説明 | 基準点 | 正の方向 | 単位 |
|--------|------|--------|----------|------|
| `roll` | 左右方向の傾き | 重力方向（静止時≈0°） | 右に傾く | 度 |

## 12. 座標系の図解

### 被験者から見た座標系

```
        前方（スクリーン）
           ↑
           |   pitch (+)
           |   ↗ (後傾)
    ←------+------→ roll (+) = 右傾
     左    |      右
           |
           ↓
        後方

     重力方向 = 下向き（new_z軸正方向）
```

### 角度の符号規則

| 動作 | roll | pitch |
|------|------|-------|
| 右に傾く | + | 0 |
| 左に傾く | - | 0 |
| 後ろに傾く | 0 | + |
| 前に傾く | 0 | - |

## 13. 計算フロー全体図

```
┌─────────────────────────────────────────────────────────┐
│  M5Stack IMU 生データ                                    │
│  accel_x, accel_y, accel_z [m/s²]                       │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  重力正規化座標変換                                       │
│  1. 時間平均で重力方向を推定                              │
│  2. 新座標系（new_x, new_y, new_z）を構築                │
│  3. 加速度を新座標系に変換                               │
│     → accel_x_norm, accel_y_norm, accel_z_norm          │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  角度計算                                                │
│                                                         │
│  roll = arctan2(ay_norm, az_norm) × 180/π              │
│       → 左右傾斜角 [度]                                  │
│                                                         │
│  pitch = arctan2(-ax_norm, √(ay² + az²)) × 180/π       │
│        → 前後傾斜角 [度]                                 │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  角度正規化（-180° ~ +180°）                             │
│                                                         │
│  normalize(θ) = ((θ + 180) mod 360) - 180              │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  角度変化（初期位置基準）                                 │
│                                                         │
│  roll_change = normalize(roll - roll[0])                │
│  pitch_change = normalize(pitch - pitch[0])             │
│                                                         │
│  angle_change = roll  （主要解析用）                     │
└─────────────────────────────────────────────────────────┘
```

## 14. まとめ表

| 項目 | Roll | Pitch |
|------|------|-------|
| **計算式** | $\arctan2(a_y, a_z)$ | $\arctan2(-a_x, \sqrt{a_y^2 + a_z^2})$ |
| **方向** | 左右傾斜 | 前後傾斜 |
| **正の方向** | 右に傾く | 後ろに傾く |
| **回転軸** | 前後軸（X軸） | 左右軸（Y軸） |
| **回転中心** | **なし**（センサの傾き） | **なし**（センサの傾き） |
| **範囲** | -180° ~ +180° | -90° ~ +90° |

## 15. この座標系を使用する理由

1. **重力補正**: M5Stackの装着角度に依存しない、重力を基準とした絶対角度を計算
2. **実験条件との対応**: GVS（前庭電気刺激）やオーディオパンニングは主に左右方向の動揺を誘発するため、rollが主要な解析対象
3. **初期位置補正**: `roll_change`、`pitch_change`により、被験者ごとの初期姿勢の違いを補正
4. **ドリフトなし**: 加速度の積分を使わないため、長時間計測でも誤差が蓄積しない

## 17. 注意事項

### 加速度センサの限界

1. **動的な動き**: 急激な動きがあると、運動加速度と重力加速度が混ざり、角度計算が不正確になる
2. **Yaw検出不可**: 水平面内の回転（体の向きの変化）は検出できない
3. **回転中心不明**: センサだけでは「どこを中心に回転しているか」は分からない

### 倒立振子モデルの限界

1. **身体は剛体ではない**: 実際は関節で曲がる
2. **複数の回転中心**: 足首だけでなく、股関節や膝も動く
3. **センサ位置依存**: 頭部と体幹で動きが異なる可能性
